## 📥 Installation Guide (Windows)

Once you have the files downloaded, follow these simple steps:

1. **Download Spicetify** (if you don't have it already)
   - Visit [spicetify.app](https://spicetify.app) and download the installer for Windows
   - Run the installer and follow the on-screen instructions - it's just a few clicks

2. **Extract Vantagraph-Custom**
   - Find the ZIP file you downloaded (usually in your "Downloads" folder)
   - Right-click it and select "Extract All"
   - Choose a folder you'll remember, like `C:\Vantagraph-Custom`

3. **Install the Theme**
   - Open the extracted folder
   - Copy the entire `Vantagraph-Custom` folder
   - Navigate to: `C:\Users\[YourUsername]\AppData\Roaming\spicetify\Themes`
   - Paste the folder there

4. **Apply the Theme**
   - Open a Command Prompt (press Windows + R, type `cmd`, press Enter)
   - Type: `spicetify config current_theme Vantagraph-Custom`
   - Then type: `spicetify apply`
   - Wait for Spotify to restart automatically

5. **Start Customizing**
   - Once Spotify reopens, look for the new "Customize" button in the sidebar
   - Click it to open the color editor
   - Start changing colors and see the magic happen in real-time

## 🛠️ Troubleshooting

**Issue: Theme not applying after install**
- Make sure you typed `spicetify apply` and waited for the automatic restart
- Verify the theme folder is in the correct location: `spicetify\Themes\Vantagraph-Custom`
- Try running `spicetify upgrade` first, then `spicetify apply` again

**Issue: Color editor not showing in Spotify**
- Ensure you're using the latest version of Spicetify
- Restart Spotify completely (check system tray and close it fully)
- Re-run `spicetify apply` to refresh

**Issue: Eyedropper doesn't work**
- Make sure you're clicking the eyedropper icon first
- Move your mouse to where you want to pick the color from, then click
- If using multiple monitors, the eyedropper works across all screens

**Issue: Can't share palettes**
- Check your internet connection
- Make sure you're logged into Spotify (this uses Spotify's built-in sharing)
